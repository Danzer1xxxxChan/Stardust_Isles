# 星屑群岛 Stardust Isles

[English README](../README.md)

一款可以在浏览器里玩的 3D 探索收集小游戏。流星雨打碎了雪山顶灯塔里的星核，玩家在群岛上收集星屑、解锁能力、帮助居民，最后登顶点亮灯塔。

所有 3D 模型、地形、音乐和音效都由代码生成，没有任何外部素材文件。

## 运行

```bash
npm install
npm run build
npm start                 # http://localhost:8080 （PORT=xxxx 可改端口）
```

开发模式：`npm run dev`（Vite 热更新，端口 5173；`/api` 会代理到 `npm start` 的服务）。

在远程服务器上运行时，用 ssh 端口转发在本机浏览器打开：`ssh -L 8080:localhost:8080 <server>`。

### 可选：AI 闲聊

设置 `ANTHROPIC_API_KEY` 后启动服务端，和居民对话时会多出「随便聊聊」选项。

```bash
ANTHROPIC_API_KEY=... npm start          # 默认模型 claude-opus-5-5，AI_MODEL=... 可替换
```

没有 Key 时游戏完全正常，只是不显示这个选项。

## 操作

| 按键 | 作用 |
|---|---|
| WASD / 方向键 | 移动（朝陡坡走会自动攀爬，消耗体力） |
| 鼠标 | 转动视角（点击画面锁定，或按住右键拖动），滚轮缩放 |
| 空格 | 跳跃；空中再按：二段跳（弹跳靴）/ 展开滑翔翼（按住） |
| Shift | 冲刺 / 快速游泳 |
| 鼠标左键 / J | 攻击（连按三段连击；空中按下是下落重击） |
| Q | 翻滚闪避（有无敌时间，消耗体力） |
| E | 互动（对话、开箱、钓鱼、营火、转镜子……） |
| C | 相机（拍照登记图鉴） |
| Tab / M / Esc | 菜单 / 地图 / 暂停 |

## 内容

- **6 个区域**：晨风草原与村庄、迷雾森林、红岩峡谷、珊瑚海岸、水晶湖、霜顶雪山。
- **能力解锁**：相机、滑翔翼、提灯、钓竿、脚蹼、铲子、弹跳靴、星屑罗盘。每种能力都会打开新的区域或玩法。
- **收集物**：30 颗星屑（集齐 20 颗可以点亮灯塔）、15 根金羽毛（提升体力上限，决定能爬多高）、约 300 枚贝壳币、10 个宝箱、8 顶帽子、41 条图鉴。
- **9 位居民，各有任务**：找羊、采蘑菇、钓鱼课、峡谷赛跑、星座石台、送热可可等。
- **星屑的获得方式**：平台跳跃、滑翔穿光环（含上升气流）、推箱子谜题、光束镜子谜题、追踪星光狐、夜晚限定的星座和萤火虫、藏宝图挖宝、钓到金鳞鱼、图鉴奖励。
- **系统**：
  - 昼夜循环（游戏里一天约 8 分钟）和下雨天气，部分动物和谜题只在特定时间或天气出现
  - 营火可以休息和快速旅行
  - 地图带战争迷雾
  - 自动存档（浏览器 localStorage）
  - 生成式背景音乐和环境音效

## v0.2：远方群岛、战斗与画质升级

评估和策划见 [UPGRADE_PLAN.md](UPGRADE_PLAN.md)。

- **无限地图**：主岛 425 m 以内保持原样，往外平滑过渡到程序化生成的「远方群岛」。区块随玩家位置按需生成和卸载，大小 75 m，有 3 级 LOD。生物群系有五种：翠屿草原、雾隐林海、赤岩荒地、霜原、晶辉海滩。东、西、西北三个方向有沙洲栈道，可以直接走过去。
- **战斗**：玩家有生命值，倒下后在最近的营火复活，并损失少量贝壳币。三段连击、下落重击、翻滚闪避，攻击会软锁定目标。打击时有顿帧、受击闪白、刀光、冲击环和伤害数字。
- **敌人「蚀影」**：史莱姆、蚀影狼、晶甲魔像（精英，砸地前有红圈预警）。等级随离岛距离提高，击败后掉落贝壳币和回复光球。主岛只在夜晚的野外出现少量史莱姆，村庄附近永远安全。
- **动物**：都有血条。受击后逃跑，倒下时化作星光，过一会儿重新出现。
- **画质**：后处理管线（泛光、GTAO、调色、暗角、SMAA/MSAA）；程序化云层；水面着色器（菲涅尔反射、高光、岸边泡沫、焦散）；约 9 万根随风摆动的草叶；植被风摆；地形细节着色；平滑着色加轮廓光的角色和动物，带完整五官；环境粒子。设置里可以切换画质（低 / 中 / 高 / 极致）。

## 多语言（中文 / English）

在标题界面右下角的「中文 / English」，或者在「设置 → 语言」里切换。游戏中切换会先存档再重新载入。

- 代码里的文案都写成 `t('中文原文')` 或 `t('现在有 {0} 颗', [n])`。中文原文就是翻译键，英文词典在 `src/i18n/en-*.js`。
- `node tools/i18n/extract.mjs` 检查有没有漏翻的文案。
- `node tools/i18n/shadow.mjs` 检查 `t()` 有没有被局部变量 `t` 遮蔽。这类问题曾导致钓鱼、赛跑等玩法报错，所以有冲突的文件改用 `import { t as tr }`。
- 开启 AI 闲聊时，英文模式下居民会用英文回复。

## 宣传片

`tools/promo/` 用游戏引擎实时演出宣传片，然后逐帧录制：

```bash
npm start                                              # 先启动游戏服务器
node tools/promo/record.mjs http://localhost:8080/     # GPU Chromium 逐帧录制 1080p30 → tools/out/promo/frames
node tools/promo/record.mjs --preview --width 1280 --height 720   # 只截每个镜头的几张关键帧，用来检查构图
node tools/promo/record.mjs --lang en                  # 英文版（游戏界面、对话和字幕都是英文）→ tools/out/promo-en
python3 tools/promo/music.py tools/out/promo/timeline.json tools/out/promo/music.wav   # 按时间线合成配乐
ffmpeg -framerate 30 -i tools/out/promo/frames/%05d.jpg -i tools/out/promo/music.wav \
  -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -shortest promo.mp4
```

`director.js` 注入页面后，会把 `requestAnimationFrame`、定时器、`performance.now` 和 CSS 动画都换成虚拟时钟，每一帧精确推进 1/30 秒，所以录制再慢，成片节奏也和真实游玩一致。镜头表写在 `director.js` 里，每个镜头包含机位路线、模拟按键、敌人生成、时间天气和字幕。

## AI 元素的评估

| 方案 | 结论 |
|---|---|
| 实时生成关卡、任务或奖励 | ❌ 不采用。生成结果不可控，会破坏能力解锁的节奏和数值平衡，而且延迟很高。 |
| 与居民自由闲聊、讨要提示 | ✅ 作为可选功能实现。 |
| 开发期用 AI 写对话和内容 | ✅ 已采用。所有剧情台词都是固定脚本，保证质量和一致性。 |

自由闲聊的实现细节：

- **服务端掌握人设和 API Key**：客户端只发送 NPC 编号、最近几轮对话和一份游戏状态摘要（未完成的目标），没法注入系统提示词。
- **回答依据真实进度**：模型根据真实的游戏进度给提示，并且被要求不编造物品、不承诺奖励。它也没有任何改动游戏状态的能力。
- **主线不依赖 AI**：主线流程完全不依赖它。开销方面，每次回复大约几百个 token，用低 effort、系统提示词做了缓存，并开启了服务端兜底。

## 代码结构

```
src/
  world/     地形（高度场+分区混合）、远方群岛流式生成（frontier.js）、草地、环境粒子、程序化模型、植被散布、建筑、天空云层、水面、碰撞
  render/    后处理管线与画质分档
  player/    角色模型与动画、控制器（走/跑/跳/滑翔/攀爬/滑落/游泳）、跟随相机
  game/      状态与存档、内容数据、收集物、居民与对话脚本、挑战与谜题、钓鱼、拍照、动物、任务、战斗（combat.js）与敌人（enemies.js）
  ui/        HUD、对话框、菜单与地图
  audio/     合成音效、生成式音乐、环境声
  ai/        AI 闲聊客户端
server/      生产服务器（静态文件 + /api/npc-chat）
tools/       functest.mjs / combattest.mjs（无头浏览器功能测试）、smoke.mjs / shots.mjs（截图）、probe.mjs（地形检查）、i18n/（翻译检查）、promo/（宣传片录制）
```

测试：先 `npm start`，再运行 `node tools/functest.mjs http://localhost:8080/`。脚本会在无头 Chromium 里模拟按键，跑完 19 项玩法检查。战斗和远方群岛用 `node tools/combattest.mjs http://localhost:8080/` 测试，截图巡游用 `node tools/shots.mjs <url> <shots.json>`。
