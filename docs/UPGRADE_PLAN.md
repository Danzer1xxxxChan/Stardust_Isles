# 星屑群岛 · 升级评估与策划（v0.2）

## 一、现状评估

| 维度 | 现状 | 主要差距 |
|---|---|---|
| 渲染管线 | 直接 `renderer.render`，ACES 色调映射，单张 2048 阴影贴图，PCF 硬阴影 | 没有后处理：没有泛光、环境光遮蔽、调色和抗锯齿后处理，发光物体看起来是平的 |
| 地形 | 900×900 m 固定高度场，`flatShading` 顶点色 | 大面积纯色，没有细节噪声；坡面、沙地、草地之间的过渡很生硬 |
| 植被 | 实例化低多边形，静止不动 | 没有风吹的动感，地面草只是零散的小锥体 |
| 天空 | 渐变天穹 + 太阳光斑 + 星星 | 没有云层，日出日落的层次也不够 |
| 水面 | 半透明平面，加上顶点正弦波 | 没有菲涅尔、高光、岸边泡沫和深浅变化 |
| 角色 | 胶囊和球体拼成，`flatShading`，五官只有两个点 | 剪影辨识度低，没有材质层次和轮廓光 |
| 动物 | 盒子和锥体拼成 | 同上 |
| 战斗 | 没有 | 没有攻击、血量和受击反馈 |
| 地图边界 | 角色被限制在 ±440 m 以内，四周是深海 | 探索的终点是可以看到的 |

**结论**：现在的瓶颈不在模型面数，而在**光照和后处理、材质细节、动态感（风、水、粒子）、反馈（战斗打击感）**这四件事上。浏览器里的零素材程序化游戏达不到 3A 游戏的水准（扫描素材、动捕、Nanite 等都用不上）。更现实的目标是**风格化画面**，借鉴《塞尔达：旷野之息》《原神》的思路，用干净的造型配合光影、氛围和反馈，尽量提升质感。

两个方向的取舍：

- **无限地图**：单纯加大地图会稀释手工内容。但它和「战斗」是互补的：手工主岛负责剧情和解谜，无限延展的「远方群岛」负责战斗、探索和刷宝。所以两个方向都做，并且让它们互相支撑。
- **画质**：按「单位工作量换来的观感提升」排序：后处理（泛光、AO、调色）> 云和天空 > 风吹草地 > 水面 > 地形材质 > 角色和动物精细化 > 粒子特效。

## 二、策划

### 1. 远方群岛：按需无限生成
- 主岛保持手工设计不变。距离中心 425–500 m 一带平滑过渡到**程序化群岛**，并向四周无限延伸。
- 世界按 75 m 的区块按需生成：玩家走到哪里就生成到哪里，远处的区块自动卸载。每个区块包含地形、植被、碰撞体、敌人和宝箱。
- 远方的海以**可涉水的浅滩**为主，中间夹着需要游泳或滑翔才能通过的深水航道。主岛东、西、西北三个方向有**沙洲栈道**，走路就能到达。
- 生物群系由低频噪声决定：翠屿（草原）、雾林、赤岩、霜原、晶滩。
- 难度随离岛距离上升：敌人等级越来越高，宝箱也越来越丰厚。HUD 显示当前群系名和离岛距离。

### 2. 战斗模组
- **玩家**：生命值条（HUD 左上角）。脱战 5 秒后自动回血，营火休息回满。倒下后在最近的营火复活，并损失少量贝壳币。
- **武器「星辉短剑」**：左键或 J 攻击，三段连击（左斩、右斩、回旋斩），空中按攻击是下落重击。Q 翻滚闪避，有无敌帧，消耗体力。攻击会软锁定附近的目标。
- **打击感**：顿帧、镜头震动、受击闪白、击退、命中火花、刀光拖尾，暴击时显示金色伤害数字和专属音效。
- **敌人「蚀影」**：史莱姆（弹跳冲撞）、蚀影狼（有预警的扑咬）、晶甲魔像（精英，范围砸地，地面有红圈预警）。远方群岛常驻敌人，主岛的野外只在夜晚出现少量，村庄永远安全。
- **动物**：都有血条。受击后惊逃，倒下时化作星光「跑回家」，过一会儿重新出现，掉落少量贝壳币（不血腥，保持治愈基调）。
- **血条**：头顶血条带名字和等级，受伤或靠近时显示。

### 3. 画质
- **后处理管线**：EffectComposer 依次做 GTAO 环境光遮蔽（极致档）、UnrealBloom 泛光、自定义调色（色彩分级、暗角、轻微色差、颗粒），最后用 SMAA 抗锯齿。
- **画质分档**：低 / 中 / 高 / 极致，在设置里切换，控制后处理、阴影分辨率、草地密度和视距。
- **天空**：程序化 FBM 云层，随风流动，会被日出日落染色；太阳加上光晕。
- **草地**：玩家周围约 7 万根实例化草叶，随风摆动，角色走过会被压弯，颜色取自地形。
- **植被**：树冠和草丛加顶点风摆。
- **水面**：重写着色器，包括法线扰动、菲涅尔天空反射、太阳高光，岸边泡沫、深浅渐变根据水深计算。水面跟随玩家移动，支持无限海域。
- **地形**：改为平滑法线，加入世界空间噪声细节（草色斑驳、泥土斑点、坡面岩层），配合 AO 和轮廓光。
- **角色**：平滑着色；眼睛有白、瞳孔和高光，加上眉毛、鼻子、嘴、刘海、衣领、腰带、手套、靴子、背包绑带；新增短剑；材质加轮廓光。
- **动物**：重做羊、鹿、狐、山羊、螃蟹、青蛙的模型（更圆润，五官更完整）；新增三种敌人的模型，带发光的核心和眼睛（配合泛光）。
- **特效**：刀光拖尾、命中火花、地面冲击环、倒下时的星光、环境浮尘和萤火。

### 4. 风险与对策
| 风险 | 对策 |
|---|---|
| 性能 | 画质分档；区块分帧生成；远处区块不生成植被；每个区块的植被合并成一次绘制 |
| 存档兼容 | 新增字段都有默认值，旧存档可以直接读取 |
| 破坏原有玩法 | 主岛 425 m 以内的地形逐点不变；功能测试脚本全量回归 |
